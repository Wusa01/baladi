# Baladi | بلدي

Baladi is an independent civic platform for reporting and tracking public service issues in N'Djamena, Chad.

## Vision

Improve public service transparency by allowing residents to report local problems, follow verified updates, and participate in improving their city.

## Initial Scope

- Water supply issues
- Electricity problems
- Roads and drainage
- Waste management
- Public facilities
- Other public service issues

## Technology Stack

- Python
- Flask
- PostgreSQL
- SQLAlchemy
- Bootstrap 5
- JavaScript
- Leaflet and OpenStreetMap (planned)

## Languages

- Arabic
- French

## Project Structure

- `app/`: Application package
- `app/models/`: Database models
- `app/routes/`: Application routes
- `app/services/`: Business logic
- `app/templates/`: HTML templates
- `app/static/`: CSS, JavaScript, and images
- `tests/`: Automated tests
- `config.py`: Application configuration
- `run.py`: Application entry point

## Development

The application will be tested and run in the Ubuntu development environment.

## Project Status

Early development: project foundation and initial landing page.
